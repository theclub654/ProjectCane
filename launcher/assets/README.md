# Launcher artwork

The launcher header uses `projectcane-logo.png`, the ProjectCane logo by k1nomoto.

The application icon uses the supplied cane artwork. `projectcane-icon.png` is
an optimized 256px PNG export with transparent margins trimmed and proportions
preserved. `projectcane.ico` contains 16, 24, 32, 48, 64, 128 and 256px exports
for the Windows launcher, setup wizard and shortcuts.

Artwork is embedded in the launcher and included in desktop/AppImage resources.
Source images are not needed at runtime.
