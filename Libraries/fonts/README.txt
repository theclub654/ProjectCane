Fonts bundled with ProjectCane's menu customization (Options > Customization > Text > Font).
All are free, redistributable fonts:
  Poppins, Lora             - SIL Open Font License 1.1 (Google Fonts)
  Lato                      - SIL Open Font License 1.1 (see LICENSE-fonts-lato.txt)
  DejaVu                    - Bitstream Vera / DejaVu license (see LICENSE-fonts-dejavu-core.txt)
  Liberation Serif          - SIL Open Font License 1.1 (see LICENSE-fonts-liberation2.txt)
  Carlito                   - SIL Open Font License 1.1 (see LICENSE-fonts-crosextra-carlito.txt)
They are copied to <exe folder>\Fonts by the post-build step. Any .ttf/.otf you put in that
folder also shows up in the Font list. Installed Windows fonts (Impact, Comic Sans, etc.) are
listed too when present.
